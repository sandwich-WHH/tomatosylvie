# 心叶 Heart Leaf · Web 原型（PWA）

> 给无处安放的情绪，一片心形的叶子。

心叶是一款面向 20-40 岁高压人群的「减压倾诉」手账式日记 App。本目录为**可交互高保真原型**：单文件 HTML，内含全部样式与逻辑，浏览器打开即用，可作为 PWA 添加到主屏。

**技术形态**：静态单页应用（HTML + CSS + JS 内联于一个文件），无构建、无后端，数据保存在本地内存。所有布局、动效、交互规则已在 `index.html` 中定稿（**v3.7**）。

---

## 快速预览

直接用浏览器打开 `index.html`，或启动本地静态服务：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 安装为 PWA

- 支持添加到主屏（`manifest.webmanifest` + `icons/`）。
- 竖屏 iPhone 优先；桌面浏览器以 390×844 手机比例居中预览。

## 交互硬规则（已写死，勿改）

> 最高优先级约束，任何改动不得破坏。

1. 写记录弹层**只允许右下角记录笔 FAB 打开**；点击周横条 / 月历任何日期**只滚动跳转**对应记录，绝不弹出弹层。
2. 顶部栏与底部 Tab 栏**永远固定**，仅中部内容滚动。
3. 弹层隐藏态由 `transform + visibility + pointer-events` 三重保证，关闭瞬间消失，无残留。

详细规范见 `design-spec.md` / `PRD.md` / `TECH_DESIGN.md`（项目根目录）。
