# 心叶（Heart Leaf）产品需求文档（PRD）

> 版本：v1.0  
> 日期：2026-08-01  
> 状态：定稿，可进入开发  
> 技术方向：iOS 原生 App（Swift + SwiftUI），最低支持 iOS 16，仅 iPhone

---

## 1. 产品概述

### 1.1 一句话定位
**心叶** 是一款面向高压人群的「减压倾诉」手账式日记 App，让用户在无人倾诉时，把碎碎念、灵感、情绪安静地写下来。

### 1.2 解决的核心问题
- 工作 / 生活压力大的人，在情绪上头时找不到人倾诉，缺少一个私密、安全、不被打扰的出口。
- 零门槛书写：打开就写，不强迫长篇大论，一个词、一句话都算记录。
- 温柔陪伴：通过手账式视觉与回顾功能，让记录成为一种治愈而不是任务。

### 1.3 目标人群
| 维度 | 描述 |
|---|---|
| 年龄 | 20~40 岁 |
| 职业 | 上班族、学生、自由职业者，工作生活压力较大 |
| 场景 | 深夜emo、通勤时、压力峰值、灵感突现、想说话但无人可说 |
| 核心诉求 | 私密记录、情绪释放、安全感、被温柔对待 |

### 1.4 产品价值主张
> 「给无处安放的情绪，一片心形的叶子。」

## 3. 数据存储模式（本期）

- **纯本地存储**：所有数据保存在设备本地。
- 存储方案：**SwiftData**（iOS 17 推荐）不可用 → 本期采用 **Core Data** 或 **SQLite**，二者兼容 iOS 16。
  - 采用 Core Data 为主，理由：成熟、与 SwiftUI 结合好、后续扩展 iCloud 同步（NSPersistentCloudKitContainer）平滑。
- 图片存储：写入沙盒 Documents / 图片目录，数据库存相对路径引用。
- 本期不做任何网络请求，保证隐私与简单性。

## 4. 功能需求详述

### 4.1 F1 记录碎碎念 / 灵感（P0）
- 入口：底部 Tab「记录」+ 时间线页右下角悬浮铅笔按钮。
- 输入：多行文本，支持换行；无字数上限（软限制 10000 字）。
- 系统自动记录：创建时间、所在日期。
- 交互：点击任意空白处或完成按钮保存；返回自动保存草稿（防误触丢失）。
- 空状态：无记录时显示手绘风提示「今天的心叶还空着，写点什么吧」。

### 4.2 F2 心情选择（P0）
- 记录前/时选择当前心情，可选也可跳过（默认为「平静」）。
- 心情集合（v1.0 固定 6 种）：
  | 心情 | 颜色 | 手写图标 |
  |---|---|---|
  | 开心 | 抹茶绿 | 笑脸 |
  | 平静 | 米黄 | 波浪线 |
  | 疲惫 | 灰蓝 | 低头小人 |
  | 低落 | 鼠尾草蓝 | 雨滴 |
  | 焦虑 | 浅橙 | 闪电 |
  | 愤怒 | 陶土红 | 火苗 |
- 心情会用于：时间线卡片底色、统计圆环图、日历色点。

### 4.3 F3 分类标签（P0）
- 记录时可打 0~3 个标签，内置三类：工作、生活、灵感。
- 后续支持自定义标签（v1.1）。
- 时间线 / 日历可按标签筛选。

### 4.4 F4 日历视图（P0）
- 顶部 Tab「日历」。
- 月视图网格：每个日期下方显示当天记录数量 / 心情色点。
- 点击日期：底部弹出 / 跳转当天记录列表。
- 「今天」高亮 + 抹茶绿描边。
- 左右滑动切换月份。

### 4.5 F5 月度日记（P0）
- 自动按自然月聚合生成「本月日记」。
- 形态：可左右翻页的册子，封面为月份 + 手绘叶形，内页按日期倒序展示该月所有记录（含心情与照片）。
- 入口：日历页右上角 / 时间线年度分隔处。
- 空月份不生成。

### 4.6 F6 随机回忆（P1）
- 入口：时间线页顶部随机按钮（骰子手绘图标）。
- 交互：点击后全屏切换动画，随机翻出一条历史记录（排除今天）。
- 连续点击可继续换；提供「关掉」返回。

### 4.7 F7 数据统计（P1）
- 入口：Tab「统计」。
- 三个卡片：
  1. **记录热力图**：月历网格，颜色深浅代表当天记录条数（1 深 → 5+ 最深）。
  2. **分类标签占比**：工作/生活/灵感占比，环形或条形 + 百分比。
  3. **心情占比圆环图**：6 种心情占比，颜色对应 4.2。
- 顶部切换「本月 / 全部」。

### 4.8 F8 照片记录（P1）
- 记录时可从相册选择一张照片（选一张，v1.0 简化）。
- 图片以缩略图显示在卡片上；详情页可查看原图。
- 删除记录时同步删除本地图片文件。

### 4.9 F9 导出 PDF（P2）
- 支持导出「单条记录」与「整月日记」为 PDF。
- 使用 PDFKit 生成，版式：米色底、手写风标题、正文、日期、心情色标注。
- 通过系统分享面板导出（可存文件/隔空投送/微信等）。

### 4.10 F10 时间线浏览（P1）
- 首页主信息流，按日期分组、倒序排列。
- 每条为手账卡片：日期+时间戳、心情色带、文本、照片、标签。
- 卡片样式：手绘信封/邮票/便签等轻量差异化边框（保持统一规范内）。

## 6. 视觉设计规范（Design System）

> 风格：喜茶式手账风 × 拙趣 × 手写感 × 清新绿。参考图置于 `references/`。

### 6.1 色彩系统（替换原参考浅黄，避免倾诉压力）
| Token | 色值 | 用途 |
|---|---|---|
| 背景·暖米 | `#F7F1E5` | 全局背景 |
| 卡片·奶油 | `#FFFDF7` | 卡片底色 |
| 主色·抹茶绿 | `#8A9B6E` | 主按钮、选中态、今天高亮 |
| 深绿·叶脉 | `#5C6B46` | 标题、描边、强调 |
| 墨色 | `#3A3A32` | 正文文字 |
| 手账描边 | `#6B6657` | 手绘线框、分隔 |
| 心情色 | 见 4.2 | 心情标识 |

设计逻辑：低饱和、暖底、绿点睛，视觉压力小、留白多。

### 6.2 字体规范
| 层级 | 字体 | 说明 |
|---|---|---|
| 标题/情感表达 | 手写体（如 `Xingkai SC` / `MaShanZheng` 风格手写） | 日记封面、心情、随机回忆 |
| 功能文字 | 系统字体 SF + 中等字重 | 按钮、列表、正文 |
| 正文记录 | 手写感系统字体（iOS 自带英文手写 + 中文楷体 fallback） | 让书写感贯穿 |

> 说明：iOS 无法打包任意中文字体（许可问题）。策略：标题用系统内置手写类字体 fallback，正文保留清晰可读性，手写感主要由版式/配色/笔触营造。具体字体方案在开发技术方案中确认。

### 6.3 组件规范
- 卡片：奶油底 + 手绘感细描边 + 圆角 16pt + 轻微偏移阴影。
- 主按钮：抹茶绿实底、墨色文字、圆角全。
- 悬浮按钮（FAB）：深绿圆形 + 手绘铅笔图标。
- 标签：圆角胶囊，浅绿描边 + 墨绿文字。
- 心情选择：横向胶囊排列，选中放大 + 底色填充。
- 空状态：手绘插画 + 一句温柔文案。
- 底部 Tab：图标线性手绘风，选中抹茶绿。
- 图标：全部采用手绘涂鸦风（可用 SF Symbols 变体 + 自定义描边叠加）。

### 6.4 版式原则
- 大量留白；行距宽松（行高 1.6+）。
- 正文左对齐，避免大段居中。
- 每屏最多 2 个层级的信息密度，突出"松弛感"。

## 7. 交互与动效
- 翻页：月度日记左右翻页（Curved 缓动，翻页 300ms）。
- 随机回忆：全屏遮罩 + 卡片翻转/缩放入场 500ms，失败态（无历史）给手绘提示。
- 保存：轻触反馈 + 短促抖动（象征叶子落下）。
- 删除：左滑 + 二次确认弹窗，弹窗手账风格。
- 全局手势：支持右滑返回；编辑页下拉收起键盘。

## 8. 数据模型（Core Data 实体）
| 实体 | 字段 | 说明 |
|---|---|---|
| Record | id, text, mood, moodColor, tags[], photoPath, createdAt, dateKey | 核心记录 |
| Tag | id, name, color | 分类标签 |
| (月度日记/统计) | 由 Record 聚合计算 | 不单独建实体 |

索引：dateKey（yyy-MM-dd）高频查询；createdAt 排序。

## 9. 非功能需求
| 项 | 要求 |
|---|---|
| 性能 | 首屏 < 2s；千条记录滚动流畅；热力图按月渲染 < 100ms |
| 隐私 | 无网络权限（v1.0），数据不出设备 |
| 兼容 | iPhone，iOS 16+，适配横屏仅允许竖屏 |
| 无障碍 | 支持动态字体、VoiceOver 基础标签 |
| 稳定性 | 输入防丢（草稿自动保存）、崩溃率目标 < 0.5% |
| 本地化 | 界面中文为主（后续可加英文） |

## 10. 技术栈方案（开发用）
| 层 | 选型 | 理由 |
|---|---|---|
| 语言 | Swift 5.9+ | iOS 16 兼容 |
| UI | SwiftUI | 声明式，页面结构清晰易改 |
| 数据 | Core Data | iOS 16 支持、后续平滑接 iCloud 同步 |
| 图片 | UIImage + 沙盒存储 | 简单可靠 |
| PDF | PDFKit | 系统框架 |
| 架构 | MVVM + 分层（View / ViewModel / Model / Service） | 便于单功能独立修改 |
| 依赖 | 优先零第三方依赖 | 简历展示更聚焦原生能力 |
| 包管理 | Swift Package Manager | 官方标准 |

## 12. 风险与注意
| 风险 | 应对 |
|---|---|
| iOS 16 无 SwiftData | 使用 Core Data，抽象 DataService 层，未来可切换 |
| 中文字体手写感受限 | 用版式/配色/笔触营造，不依赖打包字体 |
| 图片占空间 | 压缩存储 + 删除时清理文件 |
| 需求蔓延 | 严格执行「本期范围」，新需求入 backlog |
