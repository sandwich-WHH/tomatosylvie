# 6 心情 AI 绘图提示词

> 适用于即梦(Midjourney/Doubao)/ Gemini Image / DALL-E / Stable Diffusion。
> 关键词:**HEYTEA 喜茶艺术家风格 + 真实物 + 简笔小人 + 莫兰迪单色点睛**。
> 生成后**必须**用 `scripts/remove-bg.py` 去除白色背景。

---

## 通用母题

每张图必须满足:
- **真实物体**(如太阳/茶杯/云/雨/闪电/乱线)
- **简笔小人**(黑色线稿,做某个动作)
- **单一莫兰迪色点睛**(整体画面只有 1 种强调色)
- **白色背景**(生成后用脚本抠成透明)
- **线条有微小抖动**(拙趣,不光滑)
- **无文字、无 emoji**

## 生成后处理流程

1. **生成** → 默认输出 PNG,白色背景,1024×1024
2. **去除白底** → 运行 `python scripts/remove-bg.py`
3. **自动裁剪** → 去除周围留白,得到紧凑尺寸(500~1000px)
4. **命名规范** → `XX_<心情>_<主体>_透明.png`,XX 为 01-06 编号
5. **放入 skill** → 复制到 `assets/mood-icons/` 目录
6. **使用** → HTML 中 `<img src="assets/mood-icons/01_开心_太阳小人_透明.png">`,无需任何包装

## 质量验收标准

- [ ] 插画线条不光滑(有手绘抖动)
- [ ] 小人有动作姿态(不是站桩)
- [ ] 只有 1 种强调色
- [ ] 整体 60%+ 留白
- [ ] 白色背景(生成后转透明)
- [ ] 无任何文字、emoji
- [ ] 元素居中或主体明确
- [ ] 1:1 正方形构图
