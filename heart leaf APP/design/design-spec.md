# 心叶 App · 完整设计规范 v2.2

> 版本说明：v2.2 为设计语言基线（莫兰迪 × HEYTEA × 手写温度），v3.7 原型 `web/index.html` 在其基础上定稿；色彩 Token 与 v3.7 一一对应，交互/布局硬规则以 `docs/PRD.md` 为准。
> **风格定调:** 莫兰迪克制 × HEYTEA 艺术家拙趣 × 手写字体温度
> **核心情绪:** 安静陪伴 / 零负担书写 / 像一个无声的朋友

---

## 一、产品定位

心叶(Heart Leaf)是一款面向 20-40 岁都市高压人群的**减压倾诉日记 App**。不只是一个记录工具,而是一个**会呼吸的树洞**:打开就能写、写什么都可以、没有任何评判、像朋友递来一杯热茶。

在 v1「莫兰迪纯净白」基础上,v2 引入「**手绘艺术家风格**」(参考喜茶 HEYTEA 视觉语言):用 **真实摄影元素 + 手绘线稿 + 极简小人(Stick Figure)+ 手写中文字体** 的组合,在克制与温度之间找到平衡——既有现代极简的高级感,又保留手作拙趣的人情味。

## 二、视觉风格 DNA

| 维度 | 莫兰迪纯净白 | HEYTEA 艺术家拙趣 | 最终融合 |
|------|----------------|-------------------|----------|
| 主色系 | 低饱和莫兰迪 | 真实物本色 + 单点强调 | **莫兰迪基调 + 单物单色点睛** |
| 图形 | 干净几何、圆角 | 手绘线稿、铅笔质感 | **几何框架 + 关键位置手绘装饰** |
| 字体 | 系统无衬线 | 手写体、中文墨迹感 | **手写体用于情感文字 + 无衬线用于功能文字** |
| 插画 | 几乎不用 | 真实物 + 简笔小人 | **心情图标用手绘小植物/小物件,关键节点用极简小人作伴** |
| 留白 | 大量白 | 大量白 | 保留并强化 |
| 阴影 | 柔和、低 | 几乎不用阴影 | 卡片用 1px 浅边框或纸纹替代阴影 |
| 动效 | 淡入上移 | 几乎静止 | 保留淡入,但**像翻书/吹动纸张**的有机感 |

**情绪关键词:** 治愈 · 安静 · 温柔 · 克制 · 拙趣 · 有呼吸感 · 现代简洁 · 低负担 · 安全感 · 留白 · 无压力 · 像树洞

## 四、字体系统(双字体)

### 4.1 字体组合

**情感层·手写体**(用于与"心"相关的文字)
- 推荐中文:`演示悠然小楷`(免费可商用,推荐!契合"树洞"气质) / `沐瑶随心手写体` / `汉仪跳跳体`
- 推荐英文:Google Font `Caveat` / `Patrick Hand` / `Shadows Into Light`
- 字重: 400-500,不用粗体
- 字间距: +1~2%
- 倾斜: 自然倾斜 -1° ~ +2°

**功能层·无衬线**(用于界面可读性优先的文字)
- 中文: `PingFang SC` / `苹方` / `HarmonyOS Sans` / `思源黑体 SC`
- 英文: `Inter` / `SF Pro`
- 字重: 400(常规)、500(中等)、600(按钮)
- 字间距: -0.5%(标题) / 0%(正文)

### 4.2 字号阶梯

```
display-l:   32px  / 1.2   手写体  开屏/品牌口号
display-m:   28px  / 1.25  手写体  首页空状态、引导
h1:          24px  / 1.3   手写体  页面标题
h2:          20px  / 1.4   手写体  区块标题、月份
h3:          18px  / 1.4   无衬线  卡片主标题
body-l:      16px  / 1.65  无衬线  正文
body-m:      15px  / 1.65  无衬线  记录正文
body-s:      14px  / 1.6   无衬线  标签、辅助说明
caption:     12px  / 1.5   无衬线  时间戳、提示
micro:       11px  / 1.4   无衬线  数据单位
统计大数字:  48px          手写体  模拟手写记账本
```

## 五、图形语言

### 5.1 视觉元素三件套(参考喜茶)

**1) 真实物 + 简笔小人的组合(核心母题)**
- 不用 emoji 表情
- 用"现实物品 + 极简线稿小人"做叙事
- 例:心情"焦虑" = 一团乱麻线条 + 小人挠头
- 绘制风格:黑色 1.5pt 线条、略微不规则的笔触

**2) 手绘线稿装饰(关键节点)**
- 心情图标(6 个):用手绘小物件代替抽象色块
- 装饰元素:小星星 ✦、小圆点 ·、小斜线 〰、小爱心 ♡、小太阳光线

**3) 真实植物/物(用于心情、节气、状态)**
- 心情卡背景:用低饱和度真实物(干花/绿叶/旧物)做 5% 透明度的水彩晕染
- 不喧宾夺主,只在用户需要"沉浸"时出现

### 5.2 禁止元素

- Emoji 作图标
- 马卡龙高饱和插画
- 拟物纹理(金属/玻璃/塑料)
- 歪扭的"丑萌"过度风格
- 商业 SaaS 渐变按钮
- **任何圆圈/方框/卡片容器圈住插画**(v2.2 终极原则)

## 七、动效与微交互(像呼吸一样自然)

### 7.1 时长与曲线

```
微交互(按钮按下):    150ms   cubic-bezier(0.4, 0, 0.2, 1)
卡片出现:            250ms   cubic-bezier(0.16, 1, 0.3, 1)  /* 弹性减速 */
页面切换:            300ms   cubic-bezier(0.32, 0.72, 0, 1)
抽屉滑入:            350ms   cubic-bezier(0.32, 0.72, 0, 1)
FAB 按下:            200ms   spring(1, 80, 10)              /* 弹性 */
手绘圈画上去:        700ms   cubic-bezier(0.4, 0, 0.2, 1)
```

### 7.2 关键动效清单

| 场景 | 动效 | 用意 |
|------|------|------|
| 卡片进入 | 淡入 + 上移 12px(250ms) | 像纸条飘落 |
| 心情选中 | SVG 手绘圈画出(700ms) + 弹性缩放 1.1 | 像用笔画个圈 |
| FAB 按下 | 缩放 0.95 + 阴影加深 | 触感反馈 |
| 抽屉打开 | 从左滑入 280px,背后遮罩透明度 0→0.4 | 柔和而非遮蔽 |
| 保存成功 | 卡片向上飘走 + 顶部小绿叶飘落 | 仪式感 |
| 长按记录 | 卡片轻微晃动(±1°,3 次) | 提示可编辑/删除 |
| 第一次打开 | 引导页小手绘小人 + 手写体"开始吧" | 陪伴感 |

### 7.3 绝对禁止
- 弹跳动画、旋转 loading
- 全屏过场动画
- 任何超过 400ms 的过渡(手绘圈除外)
- 弹窗/Toast 带震动反馈

## 九、可访问性 & 包容性设计

- 所有交互元素最小 44×44px(FAB 60×60,主按钮 48px)
- 文字与背景对比度 ≥ 4.5:1
- 支持系统字号放大
- 支持深色模式
- 不依赖颜色单独传达信息(心情图标 + 文字 + 颜色三重编码)
- 减少动效模式(支持 prefers-reduced-motion)
